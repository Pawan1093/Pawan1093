## 🚀 Featured Projects

### 🏥 [Prescription Error Detector](https://github.com/Pawan1093/Prescription-Error-Detector)
> AI safety system for handwritten medical prescriptions

- Fine-tuned **BioBERT** for medical NER achieving **F1 score of 0.867**
- Built a 4-layer entity extraction pipeline: BioBERT + biomedical NER + positional rules + regex
- **EasyOCR + OpenCV** preprocessing pipeline handling real-world handwriting (avg confidence: 0.42)
- Reduces pharmacist verification time from **2+ minutes → under 3 seconds**
- Detects drug interactions, overdoses, underdoses across 20 drugs & 10 critical interaction pairs

`Python` `PyTorch` `BioBERT` `HuggingFace` `EasyOCR` `OpenCV` `Streamlit` `Gradio`
